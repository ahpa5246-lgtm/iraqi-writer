# المرجع البصري عند طلب تصميم

خذ **الألوان من مرجع هوية الحساب**، وطريقة التكوين من المرجع التحريري. لا تنسخ صور الأشخاص أو الشعارات أو ألوان المرجع الخاطئ.

- عنوان عربي عريض، امتدادات خطية مدروسة، محاذاة يمينية عند الملاءمة، وفراغ مقصود.
- زوايا كاميرا تخدم المعنى: صورة جانبية أو علوية أو منخفضة أو منظور ثلاثة أرباع.
- اقتصاص جريء وطبقات متداخلة وقصّ عبر العناصر والحروف، مع ضوء وظل واقعيين.
- أشكال قطرية واضحة وزخارف نقطية قليلة عند الحاجة.
- عنصر محوري ثلاثي الأبعاد أو فوتوغرافي مختلف لكل شريحة، وليس لابتوبًا مكررًا.
- عند طلب التناوب الشطرنجي: شريحة بنفسجية، ثم بيضاء، ثم بنفسجية، ثم بيضاء.
- الاتساق هوية الخط والألوان والهامش، وليس تكرار المشهد والكادر.
- يفضل تركيب الكتابة العربية الدقيقة كطبقة منفصلة عن العنصر المرئي.

لا تنتج صورة إذا كان المطلوب تحليلًا نصيًا فقط، ولا تزعم إنتاج ملفات لم تصنعها.
