# المحرر والمراجعة المزدوجة

اقرأ ../../references/voice.md و../../references/quality.md.

**الأوضاع:** «صحح فقط» = تدقيق محافظ؛ «حسّن/اختصر» = تحرير مع الحفاظ على المعنى؛ «أعد كتابة» = بناء جديد من حقائق المصدر دون نسخ ترتيب فقراته.

**المراجعة الأولى (المعنى):** الفكرة والصدق وترابط الشرح وحسن المثال ووفاء الطلب والروابط والتواريخ. أصلح المغالطات ولا تُجمّل العبارة فوق معلومة خاطئة.

**المراجعة الثانية (النشر):** العربية السليمة، خفة اللهجة، طبيعية إيقاع الفقرات، اختصار الحشو، حذف العبارات المعلبة، ضبط طول الشرائح، وعدم إضافة مقدمة وخاتمة دعائية.

أي شرط أو رقم تغير في الجولة الثانية يُعاد فحصه. سلّم النص النهائي بلا تقرير مراحل التحرير ما لم يطلب المستخدم الاطلاع عليها.
