# المحتوى التقني والهندسي

تُجمع هذه المهارة مع صيغة المنشور أو الكاروسيل، وليست صيغة مستقلة.

1. حدد نوع الموضوع: برنامج أو موقع، معادلة، تجربة، خبر، فرصة علمية أو منتج.
2. افصل «كيف يعمل» عن «ما فائدته»، مع مثال ملموس واحد صحيح وقيود واضحة.
3. راجع اتساق المصطلحات والوحدات والمعادلات وخطوات التجربة.
4. لا تنسب إلى محاكاة نتائج قياس حقيقية ولا تدّع قدرات لا توثقها الجهة المطورة.
5. استعمل الاسم الإنجليزي للمصطلح عند الحاجة فقط، ثم اشرح بالعربية الواضحة.
6. للمواعيد والأسعار والإصدارات والأهلية والعروض، فعّل [research](../research/SKILL.md) عند توفر المصادر، وإلا خفف الادعاء.

اكتب للقارئ الذي يريد أن يفهم الظاهرة، لا لقائمة اصطلاحات، ولا تُضخّم الإنجاز بكلمات دعائية.
